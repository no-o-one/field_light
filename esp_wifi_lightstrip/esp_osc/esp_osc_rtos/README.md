# Check XTAL crystal freq!
The reason why some of our ESP32 modules were operating on the wrong baud rate (for any comms, including serial) is their crystal frequency, which is basically the clock that controls this stuff. By default its 40MHz, some of our modules had it 26MHz, so the compiler would generate the multipliers for 40MHz, while in reality they would be applied to 26MHz. To check the particular chip's crystal frequency with esptool run ```py -m esptool --port [port] chip_id```, should output a bunch of info about the chip including the crystal frequency.
